# 보이스 데이터 운영 가이드

## 1. 목적
- 포켓몬 관련 보이스 데이터를 프로젝트에서 어떻게 분류하고 관리할지 정의한다.
- 공식 문서/공식 데이터 외의 제3자 출처를 검토할 때 필요한 기준을 정리한다.

## 2. 기본 원칙
- 출처 표기는 필수지만, 출처 표기만으로 사용 가능성이 확보되지는 않는다.
- 일반 사용자가 업로드한 영상/음성은 권리 상태가 명확히 확인되기 전까지 프로젝트 자산으로 채택하지 않는다.
- 프로젝트는 무단 업로드를 수집하는 시스템이 아니라, 권리 상태를 검토한 자산만 연결하는 시스템으로 설계한다.
- YouTube, 방송 클립, 게임 리소스, 공식 캐릭터 음성을 추출해 STT/TTS/STS 학습 데이터로 쓰지 않는다.
- STS/TTS는 직접 녹음, 명시적으로 허가받은 성우/화자 음성, 공개 라이선스가 합성 학습과 서비스 사용을 허용하는 데이터만 사용한다.
- AI 생성 음성은 허용할 수 있으나, 특정 공식 캐릭터/성우 음색을 모방하거나 공식 음성과 혼동되도록 만드는 목적은 허용하지 않는다.
- 허용 범위는 “빠르고 밝은 전기 디바이스 질감” 같은 고수준 스타일을 가진 독자 합성 음성이다.
