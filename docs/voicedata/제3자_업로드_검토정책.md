# 제3자 업로드 검토정책

## 1. 목적
- 공식 문서/공식 데이터가 아닌 제3자 출처 보이스 데이터를 어떤 조건에서 검토할지 정의한다.

## 2. 허용 대상
- 업로더 본인이 직접 제작했고, 프로젝트의 보관/변환/배포를 명시적으로 허락한 음성
- 프로젝트 팀이 별도로 사용 허락을 확보한 음성
- STS/TTS 학습과 앱 제공이 라이선스상 허용된 공개 음성 데이터
- 특정 공식 캐릭터/성우를 모방하지 않는 독자 AI 합성 음성

## 3. 비허용 대상
- 프로젝트 팀이 사용허락을 받지 않은 공식 채널 영상/음성
- 출처의 권리자가 Nintendo, The Pokemon Company, 포켓몬코리아 등으로 명시된 음성
- YouTube 일반 업로드에서 추출한 캐릭터/성우 음성
- 특정 캐릭터나 성우 음색을 복제하기 위한 voice conversion 학습 데이터
- 공식 음성과 혼동될 만큼 유사하게 들리도록 의도한 AI 생성 음성

## 4. 유튜브 일반 사용자 업로드 활용 원칙
- 유튜브 URL은 `출처 기록` 용도로는 남길 수 있다.
- 그러나 URL 기록만으로 수집·보관·재배포 가능 자산으로 간주하지 않는다.
- 활용 후보는 `third_party_original` 또는 `permission_granted` 상태가 확인된 경우로 한정한다.
- `distribution_scope = internal_only`, `review_status = pending` 상태의 자료는 앱 연결, 모델 학습, STS/TTS 생성에 사용하지 않는다.

## 5. 출처 명시 방안
- 자산 레코드에 `source_url`, `source_channel_name`, `collected_at`을 필수 저장한다.
- 설명 문서에는 "출처 기록"과 "사용 허락 상태"를 분리 표기한다.
- 예시 표기:
  - 출처: `YouTube / channel-name / uploaded 2025-11-03`
  - 권리 상태: `permission_pending`

## 6. 추천 운영 방식
1. 일반 사용자 업로드는 우선 `사용 링크`로 저장한다.
2. 실제 자산 등록은 업로더 직접 창작 여부 또는 허락 여부 확인 후 진행한다.
3. 확인 전 단계에서는 앱 연결을 막고 인벤토리 문서에만 보관한다.
