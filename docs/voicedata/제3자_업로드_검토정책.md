# 제3자 업로드 검토정책

## 1. 목적
- 공식 문서/공식 데이터가 아닌 제3자 출처 보이스 데이터를 어떤 조건에서 검토할지 정의한다.

## 2. 허용 대상
- 업로더 본인이 직접 편집하거나 제작한 `음성`
- 업로더가 직접 업로드 한 자료.
- 프로젝트 팀이 별도로 사용 허락을 확보한 포켓몬코리아의 음성

## 3. 비허용 대상
- 프로젝트 팀이 사용허락을 받지 아니한 포켓몬코리아에서 직접 업로드한 영상
- 출처에 사용허가가 포켓몬코리아로 명시되어 있는 경우
- 업로드 자료 권리관계가 명확히 포켓몬코리아인 경우 

## 4. 유튜브 일반 사용자 업로드 활용 원칙
- 유튜브 URL은 `출처 기록` 용도로는 남길 수 있다.
- 그러나 포켓몬코리아가 직접 업로드한 영상이라는 이유만으로 수집·보관·재배포 가능 자산으로 간주하지 않는다.
- 활용 후보는 `third_party_original` 또는 `permission_granted` 상태가 확인된 경우 이거나, 포켓몬코리아의 공식 음성인 경우로 한정한다.
- `distribution_scope = internal_only`, `review_status = pending` 으로 유지된 경우 내부 검토가 끝나고 사용가능 자료로 허가한다.

## 5. 출처 명시 방안
- 자산 레코드에 `source_url`, `source_channel_name`, `collected_at`을 필수 저장한다.
- 설명 문서에는 "출처 기록"과 "사용 허락 상태"를 분리 표기한다.
- 예시 표기:
  - 출처: `YouTube / channel-name / uploaded 2025-11-03`
  - 권리 상태: `permission_pending`

## 6. 추천 운영 방식
1. 일반 사용자 업로드는 우선 `사용 링크`로 저장한다.
2. 실제 자산 등록은 업로더 직접 창작 여부 또는 허락 여부 확인 후 진행한다.
3. 확인 전 단계에서는 앱 연결을 막고 인벤토리 문서에만 보관한다.
