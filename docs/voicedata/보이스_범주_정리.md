# 보이스 범주 정리

## 1. 범주 목적
- 프로젝트에서 다룰 수 있는 포켓몬 보이스 자산을 범주별로 구분한다.
- 같은 "보이스"라도 권리 상태와 운영 방식이 다르므로 테이블 단위로 분리 관리한다.

## 2. 권장 범주

| 범주 | 설명 | 예시 | 권장 필드 | 기본 배포 범위 |
| :-- | :-- | :-- | :-- | :-- |
| `character_voice` | 캐릭터 또는 포켓몬의 음성 표현 | 애니 더빙 대사, 포켓몬 이름 호명 | `voice_locale`, `voice_actor_name`, `series_name` | `internal_only` 기본 |
| `ecological_sound` | 캐릭터 연기보다 효과음에 가까운 사운드 | 자체 제작 울음소리, 환경음 | `sound_style`, `creator` | `public` 가능 |
| `narration_clip` | 설명/예고/진행자 음성 | 예고편 나레이션, 소개 음성 | `speaker_role`, `episode_ref` | `internal_only` 또는 `blocked` |
| `fan_created_voice` | 제3자가 직접 창작한 음성 | 커버 더빙, 패러디, 오마주 연기 | `creator_channel`, `proof_of_permission` | 권리 확인 후 결정 |

## 3. 프로젝트 적용 우선순위
1. `ecological_sound`
2. `fan_created_voice` 중 권리 확인 가능한 항목
3. `character_voice` 중 내부 검토 완료 항목

## 4. 운영 메모
- 초기 MVP에서 공개 배포 가능한 자산은 `ecological_sound` 위주로 구성하는 것이 안전하다.
- `character_voice`는 내부 검토용 인벤토리로 관리하고, 공개 빌드에서는 필터링한다.
- `fan_created_voice`는 일반 유튜브 업로드 전체를 의미하지 않는다. 원저작권 침해 가능성이 없는 창작형 업로드와 명시적 사용 허락이 있는 경우만 후보로 본다.
