# 보이스 메타데이터 수집안

## 1. 목적
- 보이스 파일 자체와 별개로, 검토와 추적에 필요한 메타데이터 항목을 고정한다.

## 2. 필수 항목

| 필드 | 설명 |
| :-- | :-- |
| `asset_id` | 자산 식별자 |
| `form_id` | 포켓몬 폼 식별자 |
| `asset_type` | `character_voice`, `ecological_sound`, `fan_created_voice` |
| `title` | 자산 표시명 |
| `source_type` | `official`, `third_party_original`, `user_provided`, `internal_reference` |
| `source_url` | 원본 게시 위치 |
| `source_channel_name` | 채널 또는 제공자 명 |
| `collected_at` | 수집일시 |
| `voice_locale` | `ko-KR` 등 |
| `voice_actor_name` | 확인 가능 시 기록 |
| `series_name` | 작품명 또는 에피소드명 |
| `rights_status` | `licensed`, `permission_pending`, `unlicensed_internal`, `blocked` |
| `proof_of_permission` | 허락 증빙 위치 또는 식별자 |
| `distribution_scope` | `internal_only`, `private_test`, `public` |
| `storage_ref` | 내부 저장 참조값 |
| `review_status` | `pending`, `approved`, `rejected` |
| `review_note` | 반려 사유 또는 특이사항 |

## 3. 수집 프로세스
1. 자산 후보 등록
2. 출처 확인
3. 권리 상태 검토
4. 메타데이터 입력
5. 내부 승인 후 저장 연결

## 4. 반려 기준
- 명확히 포켓몬코리아의 자산이라고 명시된 경우에만 반려

## 5. 예시 레코드

```json
{
  "asset_id": "uuid",
  "form_id": "uuid-form",
  "asset_type": "fan_created_voice",
  "title": "피카츄 한국어 팬 더빙 샘플",
  "source_type": "third_party_original",
  "source_url": "https://youtube.com/watch?v=example",
  "source_channel_name": "creator-name",
  "collected_at": "2026-03-10T21:36:00+09:00",
  "voice_locale": "ko-KR",
  "voice_actor_name": null,
  "series_name": null,
  "rights_status": "permission_pending",
  "proof_of_permission": null,
  "distribution_scope": "internal_only",
  "storage_ref": "private_assets/voices/ko-KR/25/base/sample.wav",
  "review_status": "pending",
  "review_note": "권리 및 사용 허락 사용자 책임"
}
```
