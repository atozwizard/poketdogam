# 공식자료 및 STS 보이스 활용 방안

## 1. 최신 결정
- YouTube, 애니메이션 클립, 게임 리소스, 공식 캐릭터 음성을 추출해 프로젝트 음성 자산으로 저장하거나 STS/TTS 학습 데이터로 사용하지 않는다.
- 로토무의 실제 음성, 특정 성우의 음색, 공식 캐릭터 보이스를 복제하지 않는다.
- 앱에는 **로토무 모티프의 독자 AI 합성 음성**만 허용한다. 목표는 “전기 디바이스 같은 활발한 안내자”이지 공식 로토무 음성 복제가 아니다.
- 공식 음성 샘플을 쓰지 않았더라도, 결과물이 공식 캐릭터/성우 음색과 혼동될 만큼 유사하도록 의도한 생성은 허용하지 않는다.

## 2. 허용되는 음성 소스
1. 프로젝트 팀이 직접 녹음한 음성.
2. 화자 또는 성우와 계약해 STT/TTS/STS 학습과 앱 제공 범위를 명시적으로 허락받은 음성.
3. 라이선스가 음성 합성 학습, 변환, 앱 배포를 허용하는 공개 데이터셋.
4. 내부 프로토타입용 무음/효과음/비식별 합성음.
5. 공식 캐릭터/성우를 모방하지 않는 독자 AI 합성 음성.

## 3. 비허용 소스
1. YouTube 영상에서 추출한 로토무/포켓몬/성우 음성.
2. 공식 채널 영상의 오디오.
3. 방송, 애니메이션, 게임, 모바일 앱 리소스에서 추출한 음성.
4. 특정 성우 또는 캐릭터 음색을 모방하도록 학습한 RVC/voice conversion 모델.
5. 공식 음성처럼 들리게 만드는 것을 목표로 한 AI 생성 음성.
6. “개인 학습용”이라는 이유만으로 권리 확인 없이 생성한 음성 자산.

## 4. STS/TTS 구현 방향
- MVP: 음성 없음. UI에 voice module 상태만 표시한다.
- Prototype:
  - 입력: 사용자 마이크 음성 또는 텍스트.
  - STT: 온디바이스 또는 로컬 Whisper 계열.
  - 응답 생성: 로컬 Dex + 템플릿 또는 로컬 LLM.
  - TTS/STS: 허가받은 원본 화자 음성, 공개 라이선스 음성, 또는 비모방 독자 AI 음성으로 만든 “전기 디바이스 보이스”.
  - 실기기 전 웹 UI: browser speech synthesis 기반 프리뷰만 제공하며 STS 완료 상태로 표시하지 않는다.
- Production:
  - 음성 모델별 라이선스 문서와 동의 범위를 `voice_assets` 메타데이터에 저장한다.
  - 모델 버전, 데이터셋 버전, 사용 범위, 삭제 요청 대응 절차를 함께 관리한다.

## 5. 로토무풍 음성 디자인 가이드
- 톤: 빠르고 밝은 안내자.
- 질감: 짧은 전기 노이즈, 톡톡 튀는 피치 변화, 기계적인 엔벨로프.
- 금지: 공식 로토무 대사/울음소리 샘플 복제, 특정 성우 음색 복제.
- 말투: UI 텍스트에서는 “-로” 같은 짧은 어미를 쓸 수 있으나, 실제 공식 대사를 복제하지 않는다.
