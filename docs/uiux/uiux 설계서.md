**로토무(Rotom)**는 포켓몬 세계관에서 도감 그 자체이자 생명체입니다. 따라서 앱의 UI는 단순한 도구가 아니라 **"내 스마트폰에 로토무가 들어와 살고 있다"**는 느낌을 주는 **'로토무 OS'** 컨셉으로 설계해야 합니다.

Upstage Solar API의 지능과 로토무의 개성을 결합한 **[로토무 스타일 UI/UX 상세 설계서]**를 제안합니다.

---

# [UI/UX 설계서] 로토무 도감 OS: 비주얼 & 인터랙션 가이드

## 1. 디자인 컨셉: "Living Rotom OS"
*   **메인 테마:** 네온 오렌지와 일렉트릭 블루가 조화된 하이테크 디지털 인터페이스.
*   **비주얼 스타일:** 홀로그램 효과, 부유하는 아이콘, 끊임없이 움직이는 로토무의 눈과 입.
*   **특징:** 2026년형 닌텐도 스위치 2의 UI 감성을 반영한 고해상도 그래픽과 부드러운 60fps 애니메이션.

---

## 2. 핵심 UI 구성 요소 (Rotom Elements)

### 2.1 메인 화면: 로토무의 '얼굴' (The Face)
*   **디스플레이:** 앱을 켜면 로토무의 커다란 눈과 입이 화면 전체를 차지하며 유저를 반깁니다.
*   **감정 엔진 (Solar 연동):** 솔라 API가 생성한 대사의 감정에 따라 로토무의 눈 모양이 실시간으로 변화합니다.
    *   *기쁨:* 눈이 반달 모양이 되며 몸체가 회전.
    *   *생각 중:* 솔라가 데이터를 처리할 때 눈에 '로딩 중' 전기 스파크가 튀며 입이 '으음~' 모양으로 변함.
    *   *놀람:* 스캔 성공 시 눈이 커지며 화면 밖으로 튀어나올 듯한 연출.

### 2.2 스캔 화면: 로토무의 '눈' (Scan Lens)
*   **UI 레이아웃:** 화면 중앙에 로토무의 눈동자 모양 조준점(Reticle) 배치.
*   **인터랙션:** 카메라가 포켓몬 굿즈나 카드를 포착하면 조준점이 전기로 지지직거리며 대상을 고정(Lock-on).
*   **실시간 오버레이:** 솔라 비전이 특징을 분석하는 과정이 텍스트 스트리밍으로 화면에 흐름. (예: `[색상 분석: 노랑] -> [특징 추출: 긴 귀] -> [매칭 중: 피카츄 89%]`)

### 2.3 도감 상세 페이지: 로토무의 '메모리' (Data Folder)
*   **카드형 레이아웃:** 포켓몬 정보가 홀로그램 카드 형태로 공중에 떠 있는 듯한 연출.
*   **동적 스태츠:** 능력치 그래프가 전력 게이지처럼 위아래로 움직이며, 메가진화나 테라스탈 버튼 클릭 시 화면 전체에 전기가 방출되는 이펙트와 함께 UI가 변신.

---

## 3. 솔라 AI 기반 인터랙티브 UI (Solar + UI)

### 3.1 로토 대화창 (Interactive Chat)
*   단순 텍스트 박스가 아닌, 로토무의 입에서 나오는 말풍선 형태.
*   **솔라의 역할:** 유저가 질문을 던지면 솔라가 답변을 생성하고, 로토무가 그 대사를 **말하는 것처럼** 입 모양 애니메이션과 보이스가 동기화(Lip-sync).

### 3.2 스마트 알림 (Rotom Alerts)
*   "로토! 근처에 새로운 포켓몬 카드가 감지됐다-로!"
*   솔라 에이전트가 유저의 수집 패턴을 분석해, 도감 미등록 포켓몬 정보를 로토무 특유의 말투로 푸시 알림 전송.

---

## 4. 사운드 및 햅틱 설계 (Sound & Haptics)

*   **사운드:** 8비트 기계음과 현대적인 신디사이저음이 섞인 '디지털 울음소리'. 메뉴 클릭 시 "삐릿-!" 하는 전자기적 효과음.
*   **보이스:** 앞서 언급한 한국어 성우의 로토무 전용 음성 데이터 활용.
*   **햅틱(진동):** 전기를 방출하는 캐릭터 특성에 맞춰, 스캔 성공이나 진화 가이드 시 미세하고 날카로운 진동 패턴(Taptic Engine 활용)으로 손맛 제공.

---

## 5. UI 시나리오 예시: "인형 스캔하기"

1.  **진입:** 유저가 앱 하단의 '로토무 렌즈' 버튼 클릭.
2.  **대기:** 로토무가 "어떤 포켓몬인지 보여줘-로!"라며 눈을 동그랗게 뜸.
3.  **스캔:** 폼본 인형을 비추면 조준점이 주황색으로 변하며 전기 이펙트 발생.
4.  **분석 (Solar):** 화면 상단에 솔라의 분석 로그가 빠르게 지나감. `[Heat Source Detected]`, `[Gen 10 Starter identified]`.
5.  **결과:** 로토무가 화면을 한 바퀴 회전하며 "성공이다-로! 이건 팔데아의 뜨거운 친구 '폼본'이다-로!"라고 외치며 도감 페이지 오픈.

### **개발 제언:**
이 UI를 구현하기 위해서는 **Unity** 또는 **Flutter**와 같은 그래픽 엔진을 사용하는 것이 좋으며, 솔라 API로부터 전달받는 **'감정 태그(Sentiment Tag)'**를 UI 컨트롤러와 연결하여 로토무의 표정 변화를 자동화하는 로직이 핵심입니다.

정말 유저가 **"로토무 도감을 실제로 소유하고 있다"**는 느낌을 받을 수 있도록, 인터페이스 곳곳에 로토무의 장난기 가득한 개성을 심어주세요!
