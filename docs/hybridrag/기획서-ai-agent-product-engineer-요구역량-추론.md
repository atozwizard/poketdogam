# 기획서: AI Agent Product Engineer 요구역량 추론

## 0. 문제정의 (왜)
- 문제: 프로덕트/솔루션 파싱 텍스트만으로 직무 요구역량을 뽑으면, 단순 빈도 기반 해석은 홍보 문구와 반복 문구에 쉽게 왜곡된다.
- 왜 그래프가 필요한가: 키워드 간 관계(선행, 개선, 상충, 평가)를 구조화해야 역량 추론의 논리 경로를 설명할 수 있다.
- 왜 VectorDB가 필요한가: 그래프 엣지의 근거가 되는 원문 문맥을 청크 단위로 검색/복원해야 추론 결과를 검증할 수 있다.
- 왜 둘을 함께 써야 하는가: 그래프는 구조적 추론, VectorDB는 문맥 근거 회수를 담당하므로, 단독 사용 대비 설명가능성과 신뢰도가 높다.
- 기대효과: 키워드 -> 관계 -> 역량 -> 근거 청크의 추적 가능 체계를 갖추어, 직무별 요구역량 산출을 반복 가능하게 만든다.
## 1. 문서 목적
- 단일 원문에서 추출한 키워드/빈도 기반 데이터로 `AI Agent Product Engineer` 직무의 요구역량을 추론하기 위한 실행 기획을 정의한다.
- 결과물은 그래프 분석과 VectorDB 검색을 함께 활용하는 하이브리드 구조를 목표로 한다.

## 2. 배경 요약
- 입력 데이터는 단어 빈도(wordfreq) 형태이며, 핵심 축은 모델/성능/품질/운영/제품화 키워드로 관찰됨.
- 단순 빈도 연결만으로는 역량 추론 신뢰도가 낮아, 역량 온톨로지/관계 타입/근거 청크가 필수임.
- 최종 목적은 "키워드 -> 관계 그래프 -> 요구역량" 추론 자동화다.

## 3. 목표
- G1. 직무 기준 역량 체계(온톨로지) 고정
- G2. 관계 의미를 타입화하여 그래프 신뢰도 향상
- G3. 원문 청크 근거를 포함한 설명 가능한 추론 구현
- G4. 그래프 결과와 의미검색(VectorDB)을 결합한 분석 파이프라인 구축

## 4. 범위
- 포함
- 키워드 정규화, 역량 매핑, 관계 그래프 구축, 근거 청크 연결, 역량 점수화
- 제외
- 채용 공고 자동 작성, HR 평가 자동 의사결정, 외부 정책 엔진 구현

## 5. 핵심 산출물
- 산출물 A: 역량 추론 결과표(역량별 점수, 근거 키워드, 근거 청크)
- 산출물 B: 관계 그래프(노드/엣지/가중치/관계타입)
- 산출물 C: 검색 가능한 청크 인덱스(VectorDB + 메타데이터)

## 6. 성공 기준 (Acceptance Criteria)
- AC1. 상위 역량 3개가 원문 문맥과 사람이 해석한 결과와 정합적일 것
- AC2. 모든 주요 엣지에 `relation_type`, `confidence`, `evidence_chunk_id`가 존재할 것
- AC3. 동일 질의 재실행 시 상위 역량 결과 편차가 허용 범위 내일 것
- AC4. 추론 결과에서 근거 청크를 역추적 가능할 것

## 7. 리스크 및 대응
- 리스크: 브랜드/공지성 단어 과대표집
- 대응: 직무-중립 키워드 감점, 역량 사전 기반 가중치 조정
- 리스크: 오탈자/깨진 토큰 노이즈
- 대응: 정규화 사전과 최소 빈도 임계치 적용
- 리스크: 단순 공출현 기반 허위 관계
- 대응: 관계 타입별 생성 규칙과 근거 문장 제약 적용
- 리스크: 한영 혼합으로 인한 매핑 누락
- 대응: 다국어 동의어 사전과 표제어 통합

## 8. 단계별 추진 계획
- 1단계: 키워드 정제/정규화 룰 확정
- 2단계: 역량 온톨로지 및 키워드 매핑 사전 확정
- 3단계: 관계 그래프 생성 및 타입 분류
- 4단계: 원문 청크 임베딩/메타데이터 적재
- 5단계: 역량 점수 산출 및 검증셋 평가
- 6단계: 대시보드/리포트 형태로 결과 제공

## 9. 의사결정 원칙
- 빈도만으로 단정하지 않고 반드시 문맥 근거를 요구한다.
- 그래프 해석은 2-hop~3-hop 중심으로 제한해 노이즈를 통제한다.
- 설명 불가능한 점수는 운영 지표로 사용하지 않는다.

## 10. 즉시 실행 체크리스트
- [ ] 역량 코드(C1~C10) 확정
- [ ] 관계 타입 사전(REQUIRES/IMPROVES 등) 확정
- [ ] 키워드 정규화/불용어/숫자 처리 규칙 확정
- [ ] 청크 스키마 및 메타필드 설계 확정
- [ ] 파일럿 문서 3건 이상으로 샘플 검증
