# 포켓덱스 Voice & Scan MVP 기능 명세서

## 1. 문서 목적
- `primary_ideation.md`의 핵심 기능을 실제 출시 가능한 MVP 범위로 확정한다.
- 화면 IA, 사용자 플로우, 기능 요구사항, 제외 범위를 명시한다.

## 2. MVP 포함 범위 확정

### 2.1 primary_ideation.md 반영 여부
- 결론: **포함 가능하며, 포함한다.**
- 포함 항목:
  - 실물 스캔으로 포켓몬 정보 조회
  - 보이스(재생 기능)
  - AI 에이전트 대화(기본형)
- 확장 보류 항목:
  - 고품질 3D 버추얼 모델링/AR (Phase 2)

### 2.2 MVP 목표
- 사용자가 `스캔 -> 포켓몬 식별 -> 정보 확인 -> 저장 -> 대화`를 1분 내 완료.
- 정보 신뢰성과 응답 속도를 우선 검증.
- **비용 제약:** 유료 클라우드 LLM/OCR 없이, 온디바이스 + Cloudflare 무료 티어만 사용.
- 상세: `docs/specs/온디바이스_무료티어_계획.md`

## 3. 사용자/시나리오
- 핵심 사용자:
  - 포켓몬 굿즈 보유 팬
  - 카드 중심 사용자
  - 빠른 진화/상성 확인이 필요한 사용자
- 대표 시나리오:
  1. 카드 스캔 후 종/폼 확인.
  2. 진화 조건과 타입 상성 즉시 확인.
  3. 보이스 듣고 AI 파트너에게 질문.
  4. 발견 포켓몬을 내 컬렉션에 저장.

## 5. 기능 명세

### 5.1 스캔 인식
- 입력: 카메라 이미지(**MVP는 TCG/문서성 카드 중심**).
- 출력: `pokemon_id`, `form_id`, 신뢰도, 후보 목록.
- 규칙:
  - 1차 OCR은 OS OCR(Apple Vision / ML Kit). 필요 시 온디바이스 PP-OCR tiny/lite 보강.
  - OCR 텍스트는 로컬 `name_aliases`에 fuzzy match하여 Top-3 후보를 만든다. 클라우드 VLM 교정 없음.
  - 신뢰도 임계값 미달 시 Top-3 후보 선택 UI 강제 + 로컬 검색 폴백.
  - 확정 전 컬렉션 저장 금지.
  - 텍스트 없는 인형/피규어 인식은 MVP 제외(Phase 2).
  - 품질 게이트: 한글 카드 `match_recall@3 ≥ 0.90` (100장 벤치, 가설→실측).

### 5.2 도감 상세 조회
- 제공 정보:
  - 이름, 번호, 타입, 세대, 폼
  - 진화 조건
  - 상성(강점/약점)
- 규칙:
  - 값이 불확실할 경우 "미확정" 표기.
  - 출처/갱신일 메타정보 노출.

### 5.3 보이스 재생
- 상세 화면에서 포켓몬별 음원 1개 이상 재생.
- 스트리밍 실패 시 텍스트 안내와 재시도 제공.
- 비배포 내부 자산은 공개 빌드에서 숨기고, 내부 QA 빌드에서만 재생 가능.
- 보이스 자산 조회 시 자산 출처/배포 범위를 함께 판별한다.

### 5.4 AI 파트너 대화(기본)
- 기능:
  - 포켓몬 관련 질문 응답
  - 진화/상성 질문 우선
- 엔진:
  - 팩트: 로컬 Dex DB 조회/계산이 진실원
  - 기본 응답: 템플릿 합성
  - 옵션: 온디바이스 1B OSS로 짧은 문장화
  - Cloudflare Workers AI는 무료 Neurons 한도 내 보조만 허용(상시 챗 백엔드 금지)
- 제약:
  - 근거 데이터 없는 응답 금지.
  - 민감/비관련 질문은 안전 응답 템플릿 적용.
  - 1B 미설치·실패 시에도 템플릿으로 degrade.

### 5.5 컬렉션 저장
- 스캔 확정 시 `discovered_pokemon` 저장.
- 중복 저장은 횟수 카운트만 증가.

## 6. MVP 제외 범위
- 유료 클라우드 LLM/OCR/VLM (`solar`, `gemini`, `gpt`, Upstage OCR 등)
- 인형/피규어 비전 인식
- 서버 Hybrid GraphRAG
- 실시간 AR 렌더링/포토모드
- 커뮤니티 피드, 사용자 간 교환
- 랭킹/대전 시뮬레이터 고급 기능
- 고급 개인화 추천(행동 예측 모델)

## 7. 비기능 요구사항
- 성능:
  - 온디바이스 스캔(매칭까지) P95 2.5초 이하(중급기 기준)
  - 상세 조회 P95 0.3초 이하(로컬 DB)
- 비용:
  - 추론 과금 0원. Cloudflare는 무료 티어 하드캡 준수
- 용량:
  - Dex SQLite ≤ 15MB(이미지 제외). 1B/PP-OCR은 옵트인 다운로드
- 보안:
  - 사용자 데이터 최소 수집. 클라우드 호출 시 TLS
- 운영:
  - OCR 엔진/모델/데이터셋 버전 로그 필수

## 8. 수용 기준(acceptance criteria)
1. 스캔 성공률(Top-3 내) 95% 이상.
2. 스캔 후 상세 진입률 70% 이상.
3. AI 대화 첫 응답 성공률 99% 이상.
4. 컬렉션 저장 실패율 1% 미만.
5. 주요 기능 크래시 프리 세션 99% 이상.

## 9. 단계별 일정(초안)
1. W1: PokéAPI → 로컬 Dex 빌드 / alias 테이블
2. W2: OS OCR + fuzzy match PoC / 카드 벤치 시작
3. W3: 상세·검색·컬렉션 / 템플릿 대화
4. W4: OCR 게이트 통과, 온디바이스 1B 옵션, 베타
