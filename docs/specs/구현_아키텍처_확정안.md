# 포켓덱스 구현 아키텍처 확정안

## 1. 목적
- 본 문서는 실제 개발 착수를 위한 구현 기준(모델, 데이터, 관측성, 구성 방식)을 고정한다.
- 범위: **무료·온디바이스 우선 MVP** + 확장 가능한 에이전트 구조.
- 상세 실행 계획: `docs/specs/온디바이스_무료티어_계획.md`

## 2. 기술 스택 확정

### 2.1 모델 전략 (2026-07-27 재확정)
- **유료 클라우드 LLM/OCR 사용 안 함** (`solar-pro2`, `gemini`, `gpt-4.1-mini`, Upstage Document OCR 제외).
- 팩트 엔진: **로컬 Dex DB (SQLite)** + 규칙/템플릿 응답.
- OCR:
  - 1차: OS OCR (Apple Vision / ML Kit)
  - 2차(선택): 온디바이스 PP-OCR tiny/lite (다운로드형)
- 챗/문장화:
  - 기본: 템플릿 합성
  - 옵션: 온디바이스 1B OSS (intent + 짧은 문장화)
- 클라우드 보조:
  - Cloudflare Workers AI **무료 할당(10,000 Neurons/day)** 안에서만
  - 용도: 임베딩·스냅샷 배포·실험. 상시 챗 백엔드로 쓰지 않음
  - 쿼터 초과 시 완전 로컬 degrade
- 라우팅 규칙:
  1. 카드 이미지 → OS OCR → 정규화 → `name_aliases` fuzzy match → Top-3
  2. 신뢰도 임계 미달 → 수동 검색 UI
  3. 질문 → 로컬 조회/계산 → (있으면) 1B 문장화, 없으면 템플릿
  4. Workers AI는 feature flag + 일일 예산 가드 뒤에만 호출

### 2.2 데이터 계층
- **핫패스(필수):** 기기 `dex.sqlite` + `name_aliases` (번들 또는 파일 다운로드)
  - 스캔/도감/매칭은 전부 여기. 상시 서버 인스턴스 없음.
- **콜드패스(선택):**
  - Cloudflare: Dex 스냅샷 파일 배포
  - Supabase: **계정·컬렉션 sync만** 후순위. 스캔/매칭 쿼리 금지
- 동접: 유저 N명이어도 스캔은 기기별 SQLite → 공유 DB 병목 없음
- 검색/추론: 로컬 fuzzy match + 로컬 상성/진화 계산
- GraphRAG/pgvector 서버: MVP 제외

### 2.3 외부 API
- 위치 기반 날씨: MVP에서 **옵션/제외 가능** (무료 키·쿼터 의존)
- 날씨 반영 챗: 로컬 동작이 우선. API 실패/미사용 시 기본 톤

### 2.4 관측성/트레이싱
- 개발 단계: 로컬 로그 + 익명 품질 이벤트(선택)
- Langfuse 등 외부 SaaS는 **유료/계정 부담 시 비활성**
- 필수 로컬 기록:
  - OCR 엔진, match score, Top-K, latency, dataset_version, on_device_llm_used

### 2.5 설정/비밀키 관리
- 최상위 `config`에서 `.env` 참조
- 원칙:
  - 코드 내 하드코딩 금지
  - 키는 Cloudflare/선택 서비스만 (`CLOUDFLARE_*` 등)
  - 온디바이스 경로는 키 없이 동작해야 함

## 3. 애플리케이션 구조 확정

핵심 플레이트는 `Graph`, `State`, `Tool`, `Node` 구조로 유지하되, **실행 위치는 모바일 로컬 우선**이다. 서버 `app/` 스캐폴드는 Dex 빌드·검증·추후 동기화 API용으로 축소 활용한다.

```text
app/
├─ config/
│  ├─ settings.py
│  └─ providers.py               # Cloudflare/optional only
├─ agents/
│  └─ pokedex_agent/
│     ├─ graph.py
│     ├─ state.py
│     ├─ nodes/
│     │  ├─ ingest_input.py
│     │  ├─ extract_scan_text.py      # OS OCR / PP-OCR 어댑터
│     │  ├─ match_local_dex.py        # fuzzy alias match
│     │  ├─ retrieve_local_dex.py
│     │  ├─ compose_answer.py         # template + optional 1B
│     │  └─ persist_trace.py
│     └─ tools/
│        ├─ tool_local_dex.py
│        ├─ tool_ocr_ondevice.py
│        ├─ tool_ondevice_llm.py
│        └─ tool_cloudflare_ai.py     # optional, budget-guarded
├─ schemas/
│  ├─ api.py
│  └─ domain.py
└─ api/                               # Dex build QA / future sync
   └─ routes/
      ├─ chat.py
      ├─ scan.py
      └─ pokedex.py

scripts/build_local_dex/              # PokéAPI → sqlite 파이프라인
```

## 4. 상태(State) 모델 초안
- `session_id`
- `input_text` / `input_image_ref`
- `intent`
- `ocr_engine` / `ocr_text`
- `match_candidates` (form_id, score)
- `entities` (pokemon/form/type/evolution keyword)
- `retrieval_context` (local dex rows)
- `llm_runtime` (`template` | `on_device_1b` | `workers_ai`)
- `llm_model_used`
- `response_text`
- `dataset_version`
- `error`

## 5. 노드(Node) 책임 분리
- `ingest_input`: 입력 정규화, intent 초분류(규칙 또는 1B).
- `extract_scan_text`: 온디바이스 OCR.
- `match_local_dex`: alias fuzzy 매칭, Top-3.
- `retrieve_local_dex`: 상세/진화/상성 조회.
- `compose_answer`: 템플릿 우선, 옵션 1B 문장화.
- `persist_trace`: 로컬 품질 로그.

## 6. 도구(Tool) 계약 규칙
- 모든 Tool은 I/O 스키마를 명시한다.
- timeout/retry 기본값을 가진다.
- Tool 실패 시 state의 `error`에 구조화 기록.
- Cloudflare Tool은 일일 Neurons 예산을 강제한다.

## 7. 에러 및 fallback 정책
- OCR/매칭 실패:
  - Top-3 → 수동 검색 → 재촬영 가이드.
- 온디바이스 1B 미설치/실패:
  - 템플릿 응답으로 degrade.
- Workers AI 실패/쿼터 초과:
  - 로컬만으로 계속.
- Dex 미적재:
  - 스냅샷 다운로드 유도, 기능 잠금 메시지.

## 8. 구현 우선순위
1. `scripts/build_local_dex` → `dex.sqlite`
2. `name_aliases` + fuzzy matcher
3. OS OCR 어댑터 + 카드 벤치
4. 템플릿 응답 + 상세/컬렉션
5. 온디바이스 1B 옵션
6. Cloudflare 스냅샷 배포(선택)

## 9. 확정된 운영 정책
1. 비용: 유료 추론 API 없음. 상시 인스턴스 없음
2. 데이터: PokéAPI → 로컬 Dex. Dex 확보와 OCR 매칭은 Local Scan Core로 병합
3. Supabase: 도감 주 DB 금지, sync 옵션만
4. OCR: OS 우선, CJK는 벤치 후 PP-OCR 보강
5. 인형/피규어 비전: MVP 제외
6. 멀티턴 메모리·컬렉션: 기기 로컬 우선

## 10. Python 실행 규칙
- 모든 `.py` 파일은 단독 실행 가능해야 한다.
- 각 파일 상단에 직접 실행 명령 주석을 둔다.
- 권장 형식:
  - `# Run: python path/to/file.py`
  - `if __name__ == "__main__": main()`
