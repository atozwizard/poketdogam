# 포켓도감 PoC 95점 품질 게이트

## 목적

15년차 프로젝트 오너와 UI/UX 리뷰 기준을 구현 가능한 체크리스트로 고정한다.
PoC 점수와 정식 MVP/Production 승인 상태를 분리해, 합성 데이터나 웹 데모가
실기기 품질로 오인되지 않게 한다.

이 점수는 구현 완성도 점수이며 정식 MVP 출시 승인이 아니다. 실물 카드, Android
실기기, 라이선스, Internal Test 게이트가 끝나기 전 Production 상태는 `No-Go`다.

다음 중 하나라도 있으면 점수와 관계없이 No-Go다.

- 이미지 파일명으로 식별 성공 처리
- 선택 포켓몬의 약점/진화 질문이 다른 facet으로 처리
- 이중 타입 상성 오류
- 출처·사용범위가 없는 데이터 포함
- 삭제할 수 없는 대화 원문 무기한 보관
- 합성 fixture를 실물 카드 OCR 성능으로 표시

## UI/UX 전문가 리뷰 반영

1. 첫 화면의 주행동을 `카드 촬영·이미지 선택` 하나로 집중한다.
2. 이름 검색은 항상 보이는 복구 경로로 제공한다.
3. 개발용 텍스트 fixture는 접힌 영역으로 격리하고 지표도 `matcher_only`로 분리한다.
4. 결과는 `이미지 스캔 → 후보 확인 → 사실 확인 → 질문 → 저장`의 번호 순서로 안내한다.
5. 자동 스캔과 자동 성공 상태를 제거해 실제 빈 상태를 보여준다.
6. 공식 참고 이미지는 렌더링하지 않고 프로젝트 작성 SVG만 사용한다.
7. 타입·스탯·필드 라벨을 한국어로 통일한다.
8. 상세에 데이터 출처·갱신일·PoC 사용범위를 노출한다.
9. 컬렉션 검색·즐겨찾기·내보내기·전체 삭제를 제공한다.
10. 360px, 키보드 focus, reduced-motion을 회귀 게이트로 둔다.

## 데이터 정책

- PokéAPI 캐시는 직접 배포 자산이 아니라 정규화 입력이다.
- 제품 DB에는 이름, 폼, 타입, 수치, 진화 조건 같은 사실·간접 필드만 남긴다.
- sprite, artwork, cry, flavor text, 카드 스캔 원본은 포함하지 않는다.
- 현재 범위는 `poc_noncommercial_evaluation`이다.
- 정식 제품 라이선스는 PoC/MVP 통과 후 신청하며, 승인 전 Production 배포는 No-Go다.

## 현재 승인 원칙

- 웹 PoC는 95점 이상이면 이해관계자 사용성 평가에 진입할 수 있다.
- Android 소스 추가만으로 P3/P4 완료 처리하지 않는다. SDK 빌드, 에뮬레이터,
  실기기 1종 증거가 있어야 완료다.
- Production은 정식 라이선스, 100장 실물 카드, Android 실기기, Internal Test 전까지 No-Go다.
