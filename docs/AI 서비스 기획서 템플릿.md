# **AI 서비스 기획서: 포켓덱스 Voice & Scan**

## **1. 도메인 선택 및 시장 분석**

### **1.1 서비스 선정 배경**

- 기존 포켓몬 정보 소비는 `텍스트 검색 중심`으로 분절되어 있다.
- 실제 팬 사용 맥락은 `굿즈 촬영 -> 정보 확인 -> 수집 기록 -> 대화/공유`의 연속 행동이다.
- ideation 문서 기준, 기회 영역은 다음 4축으로 명확하다.
  - 실물 스캔 인식
  - 멀티미디어 보이스/사운드
  - AI 에이전트형 코칭
  - 3D/AR 몰입형 뷰어

### **1.2 시장 현황 및 가치**

- 시장 구조:
  - 공식/비공식 포켓몬 정보 사이트 다수 존재.
  - 기능은 강하지만 UX가 분산(검색, 위키, 커뮤니티, 영상이 분리).
- 현재 공백:
  - 실물 입력 기반 즉시 인식 + AI 대화형 도감의 통합 서비스 부족.
- 기대 가치:
  - 학습/수집/커뮤니티 활동 시간을 단축.
  - 신규 유입(어린이/가족)에게 진입장벽을 낮춤.
  - 핵심 팬에게 폼/진화/상성 정밀 데이터 경험 제공.

### **1.3 근본 원인 분석: 5 Whys**

1. 왜 팬이 정보를 반복 검색하는가?  
   - 필요한 정보가 한 곳에 통합되지 않음.
2. 왜 통합되지 않는가?  
   - 도감 데이터, 미디어, 전략 정보의 스키마가 분리됨.
3. 왜 스키마가 분리되는가?  
   - 공식/비공식 출처마다 기준 ID/명칭/갱신 주기가 다름.
4. 왜 사용자 체감이 나쁜가?  
   - 검색 결과를 사용자가 직접 검증/비교해야 함.
5. 왜 이 문제가 지속되는가?  
   - 서비스가 "정답 검색"에 머물고 "행동 워크플로우 자동화"를 제공하지 않음.

### **1.4 핵심 페인 포인트 및 기회**

- 페인 포인트
  - 유사 폼 구분 난이도 높음.
  - 출처별 정보 불일치.
  - 모바일에서 반복 검색 피로.
- 기회
  - Vision+LLM 결합으로 `즉시 인식 + 맥락형 설명` 제공.
  - 컬렉션 로그 기반 개인화 추천 가능.
  - AR/보이스 확장으로 체류시간과 재방문율 상승 가능.

## **2. 주요 AI 도입 사례**

### **2.1 국내 사례 분석**

- 캐릭터/콘텐츠 앱에서 AI 적용 패턴
  - 이미지 기반 검색/추천
  - 대화형 가이드봇
  - 개인화 피드
- 시사점
  - 검색 정확도보다 `행동 완료율`이 리텐션에 더 큰 영향.
  - 저연령 사용자 고려 시 단순 UI와 짧은 피드백 루프가 중요.

### **2.2 해외 사례 분석**

- 게임 위키/팬덤 플랫폼 패턴
  - 방대한 데이터 탐색에 강점
  - 실시간 상호작용 UX는 상대적으로 약함
- AI 동향
  - 멀티모달 입력(이미지/텍스트) + 대화형 안내 결합 서비스 증가.
- 시사점
  - 포켓덱스는 "정보량" 경쟁보다 "완료 경험" 경쟁이 유리.

## **3. 전략적 서비스 도출**

### **3.1 성공 및 실패 사례 분석 비교**

- 성공 패턴
  - 핵심 유즈케이스 1개(예: 스캔 인식)를 압도적으로 빠르게 제공.
  - 결과 신뢰도를 사용자에게 투명하게 노출.
- 실패 패턴
  - 기능 과다로 첫 사용자가 가치 체감 전에 이탈.
  - 출처 불명 데이터로 신뢰 상실.
- 적용 결론
  - MVP는 `스캔 -> 도감 확정 -> 저장`에 집중하고, 고급 기능은 단계적 출시.

### **3.2 차별화 전략**

- 차별화 1: 폼 단위 정밀 인식
  - 종 인식이 아니라 `form_id`까지 식별.
- 차별화 2: 근거 기반 응답
  - 모든 주요 답변에 데이터 근거/출처 시점 표시.
- 차별화 3: 경험 연속성
  - 스캔 결과에서 상성, 진화, 대화, AR로 즉시 이동.
- 차별화 4: 개인화 컬렉션 운영
  - 발견 이력/관심 타입 기반 추천 경로 제공.

## **4. 서비스 상세 기획**

### **4.1 핵심 가치 및 정의**

- 서비스 정의:
  - "실물에서 시작하는 AI 도감 경험 플랫폼"
- 핵심 KPI:
  - 스캔 성공률, 스캔 후 상세 진입률, 7일 재방문율, 오답 신고율.
- 핵심 성과 목표(초기):
  - 스캔 Top-1 정확도 85% 이상.
  - P95 응답 2.5초 이내.
  - 오답 신고율 3% 이하.

### **4.2 타겟 유저 정의**

- 1차 타겟:
  - 포켓몬 카드/굿즈를 보유한 팬층(중학생-성인).
- 2차 타겟:
  - 자녀와 함께 사용하는 가족 유저.
- 3차 타겟:
  - 전략 정보(상성/진화 조건)를 빠르게 확인하려는 코어 유저.

### **4.3 가치 제안 비교**

| 구분 | 기존 정보 탐색 방식 | 포켓덱스 Voice & Scan |
| :---- | :---- | :---- |
| 입력 방식 | 키워드 검색 | 카메라 스캔 + 대화 |
| 정보 신뢰 | 출처별 상이 | Canonical DB 기준 |
| 사용 시간 | 길고 분절됨 | 짧고 연속됨 |
| 확장 경험 | 읽기 중심 | 듣기/대화/AR |

### **4.4 핵심 기능 정의**

1. 로토무 AI 스캔
   - 인형/카드/피규어 인식, Top-3 후보 제시, 확정 저장.
2. 도감 통합 뷰
   - 종/폼/진화/타입/상성/서식 정보 통합.
3. 보이스 & 생태 사운드
   - 캐릭터 보이스와 생태 음원 모드 분리 제공.
4. AI 파트너 코칭
   - 진화 조건 트래킹, 질문형 배틀 힌트 응답.
5. 컬렉션 & 리마인드
   - 발견 도감, 미완성 진화 조건 알림, 맞춤 추천.

### **4.5 기술 아키텍처 및 스택**

- 앱/클라이언트
  - 모바일 앱(iOS/Android), 카메라 모듈, AR 렌더러.
- AI 계층
  - Vision 분류 모델(종/폼), OCR, LLM 응답 합성.
- 데이터 계층
  - Canonical RDB(`pokemon_id`, `form_id`), 검색 인덱스, 캐시.
- 품질/운영
  - Guardrail 검증, 이벤트 로깅, 모델/데이터 버전 추적.
- 보안/권리
  - 자산 사용 범위별 접근 제어, 출처/라이선스 메타데이터 관리.

## **5. 비즈니스 모델 및 로드맵**

### **5.1 수익 구조 및 비즈니스 전략**

- 수익 구조(혼합형)
  - Freemium: 기본 도감/스캔 무료, 고급 기능 구독.
  - Premium: 고급 AR 씬, 고해상도 사운드팩, 심화 분석 리포트.
  - B2B 제휴: 카드샵/이벤트 연동 스캔 미션, 공동 프로모션.
- 비즈니스 전략
  - 초기: 스캔 정확도와 속도로 핵심 팬층 확보.
  - 중기: 컬렉션/커뮤니티 기능으로 네트워크 효과 확보.
  - 장기: 글로벌 다국어 및 공식 파트너십 확장.

### **5.2 단계별 로드맵**

1. Phase 1 (0-3개월): MVP
   - 스캔, 도감 상세, 상성 계산, 컬렉션 저장.
2. Phase 2 (4-6개월): 몰입형 기능
   - 보이스/사운드 라이브러리, AI 파트너 대화.
3. Phase 3 (7-12개월): 확장/수익화
   - AR 고도화, 구독 상품, 제휴 이벤트.

### **5.3 성공 지표**

- 제품 지표
  - 일일 스캔 수, 스캔 성공률, 상세 체류시간, 재방문율.
- 비즈니스 지표
  - 구독 전환율, 월 반복 매출(MRR), 제휴 캠페인 성과.
- 품질 지표
  - 오답 신고율, 수정 요청 처리시간, 모델 드리프트 지수.
